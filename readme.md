# Simple Node.js Server

## Description
This project is a simple web server created using Node.js.
It uses the HTTP module to handle requests and display HTML pages.

## Features
- Home page
- About page
- Contact page
- 404 error for invalid routes
- Basic error handling

## Requirements
- Node.js

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   node server.js

4. Open your browser and visit:

   http://localhost:3000

## Routes
- / : Home page
- /about : About page
- /contact : Contact page
